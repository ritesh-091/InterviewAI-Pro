# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within InterviewAI Pro, please do NOT create a public GitHub Issue. Instead, report details to our security desk via email: `security@interviewai.dev`.

We aim to evaluate the vulnerability details and respond with a security patch version within 48 hours.
